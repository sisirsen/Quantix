# Quantix Calculator

A modern, responsive calculator built using React. Quantix focuses on clean UI, and accurate mathematical operations.

# Live Link

https://quantix-mu.vercel.app/

#Features

* Basic arithmetic operations: Addition, Subtraction, Multiplication, Division
* Real-time input display
* Clear (`C`) and delete (`X`) functionality
* Support for parentheses `()` for complex expressions
* Responsive and minimal UI design


# Tech Stack

* React
* Tailwind CSS 
* HTML


# How It Works

* User inputs are captured through button clicks
* The input string is dynamically updated in the display
* Mathematical expressions are evaluated using JavaScript logic
* Special buttons:

  * `C` → Clears entire input
  * `X` → Deletes last character
  * `=` → Evaluates the expression
